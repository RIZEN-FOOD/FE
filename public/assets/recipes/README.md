# 레시피/조리 사진

"이렇게 즐겨보세요" 갤러리(RecipeGallery)에서 쓰는 실제 요리 사진 자리.

## 넣는 법

1. 이 폴더에 사진을 넣는다. 파일명은 자유.
2. `FE/src/components/store/RecipeGallery.tsx` 의 `ideas` 배열에서
   해당 항목에 `imageSrc: "/assets/recipes/파일명.jpg"` 한 줄만 추가한다.
   → 그릇 도형+토핑 대신 이 사진이 바로 쓰인다.

## 권장 규격

- 세로형 4:5 비율에 가깝게 (카드가 세로로 길다)
- 1200px 이상 긴 변
- 배경까지 포함된 완성 사진 OK (재료 누끼처럼 투명 배경일 필요 없음)

## 새 조합(레시피)을 추가할 때

`ideas` 배열에 새 항목을 하나 더 넣으면 갤러리에 카드가 하나 늘어난다.
문구는 조리 방법·재료·질감만 쓴다. 효능·효과를 암시하는 표현은 쓰지 않는다
(식품표시광고법, CLAUDE.md 규칙 1).
